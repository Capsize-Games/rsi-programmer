For example, the learner constructed the equivalent of:

```python
def process(items: list[int]) -> int:
    acc = 0
    for value in items:
        if value > 0:
            acc = acc + value
    return acc
```

## Evidence and scope

All six complete task functions were excluded from the 366 teacher
functions by their behavior on 24 fixed probe arrays. This is finite-probe
separation, not a proof of separation on all inputs. Supervision contains
12,614 next-token states generated by the task engine, without an LLM
teacher. The accepted recipe used 30 epochs and took 6.237 seconds including
teacher preparation. Training fingerprints are recorded; evaluation aborts
if neural parameters change during inference or evaluation.

The controller sees the original observed pairs, its actual token prefix
and outputs of a syntactically completed prefix on those observed inputs.
Completion uses fixed defaults and reads no target to choose them. The
model then receives those outputs and residuals against the observed
targets. Held inputs never enter this programming interface.

Search uses the top four well-typed neural choices at each step, retains 32
prefixes and allows at most 32 tokens. A program must explicitly return and
stop. Observed examples decide when search can return a candidate; a
separate interpreter, independent task oracle and actual target-language
executions decide acceptance on held inputs. A mismatch is retained as a
failure, with no held-guided retry.

The 20 held inputs include empty input, zero, nonpositive input, mixed
duplicates, 201 descending integers and 15 seeded random arrays. Python ran
as isolated file-processing processes with the existing namespace and
resource limits. CURLEE used its existing guard and fuel-limited VM; the
compiler binary hash stayed
`412d0e6ee5b8fb9e380322683863849523e1a5797e7e7dbd42bf174b138555ac`.
Both compiler check and VM execution were required for every counted case.
A deliberately wrong expected CURLEE result was rejected.

The emitter supplies imports, function signatures, the initial accumulator,
variable names, signed-remainder support, loop-bound contracts and CLI
plumbing. The learner chooses whether to iterate, the condition tree, the
accumulator update expression and the return expression. It does not choose
a whole `sum_positive` implementation from a library.

The supported statement language has one accumulator, one bounded input
loop, nested conditions, integer expressions and an integer return. It has
no arbitrary imports, strings, user-defined functions, natural-language
request interface, repository editing or general program repair. Reported
executions cover these sampled inputs; they do not qualify arbitrary code,
the compiler generally, or all signed-integer overflow behavior.

## Reproduce

Use fresh output directories and run commands sequentially:

```sh
flock -n /tmp/rsi-programmer-builder.lock \
  env OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 .venv/bin/python \
  -m scripts.measure_statement_programs --execution-features \
  --output /tmp/statement-programs-new

python3 /home/joe/Projects/curlee/scripts/run_limited.py \
  /usr/bin/python3 -m scripts.check_statement_curlee \
  --compiler /home/joe/Projects/curlee/build/linux-debug/curlee \
  --output /tmp/statement-programs-new
```

Omit `--execution-features` for the static recipe; add `--epochs 100` for
the longer fit. The original fixture remains frozen at the initial
30-epoch recipe. The accepted follow-up is a development choice.

The 19 focused checks passed in 0.612 seconds. They cover typed syntax,
scope, bounds, independent execution, standalone scalar CLI behavior,
partial-prefix features, teacher separation and track ownership. Logs,
source hashes and exclusions are in the [validation receipt](
../../artifacts/statement-validation-20261101/receipt.json). Full programmer
lanes, the aggregate suite and final evaluation were not rerun for this
checkpoint; remote CI remains pending.

The immediate gaps are the two unresolved tasks, ambiguity in sparse
examples, transfer to new statement structures, stronger independent task
evaluation, and evidence of benefit against classical search at matched
total cost. Bounded counterexample-guided resynthesis can test repair
without exposing held evaluation rows. Reusable fragments and learner
self-improvement still require separate demonstrations.
